# Бот 24/7 «только лимитки»

Тот же сеточный бот, что `bot.py` в корне, но по правилам HTML-версии: по рынку не входит и не выходит.
Все сделки — лимитки Post-Only; единственный выход по рынку — аварийный стоп (цена ушла от цены запуска
на заданный %, по умолчанию 10%, против позиции) и защита у ликвидации.

Railway: отдельный проект `grid-pro-html`, Root Directory `/bot24`, Volume на `/data`, регион Европа,
переменная `APP_PASSWORD` обязательна. Ключ Bybit — в Variables (`BYBIT_API_KEY`, `BYBIT_API_SECRET`) или на странице.
Пересобирается только при изменениях в папке `bot24`.
