# Grid Pro — Sell-грид-бот для Bybit

Только Sell-сетки (шорт) на USDT-perp. Без авто-бота и лишнего.

## Что умеет

- **Только Sell.** Sell-лимитки стоят на линиях выше цены. Исполнился Sell — на линию ниже ставится Buy-тейк reduce-only (только закрывает этот шорт, никогда не откроет лонг). Тейк исполнился — на той же линии снова Sell.
- Диапазон ставится так, что цена у его низа (10% ширины ниже цены, 90% выше). Сетка идёт за ценой, если цена вышла из диапазона.
- Одинаковые лоты или **геометрическая сетка** (лот растёт от цены к краю диапазона).
- **Поиск монеты на 1 час:** самые волатильные за 5 минут без пробоя, час без тренда, цена в верхней части канала. Кнопка «Взяти» заполняет форму готовой Sell-сеткой.
- **⚡ Найти и запустить Sell-сетку на N% депозита** (по умолчанию 90%): остаток всегда свободен для перестановки лимиток. Запуск только после подтверждения.
- График: Heikin Ashi / Renko / свечи, таймфреймы от 1 секунды, OI, CVD, горизонтальные объёмы, линии лимиток и позиции; таблица открытых заявок.
- Экстренное закрытие сетки или всех сеток: снять лимитки бота и закрыть позицию рынком.
- Критический стоп-лосс (по умолчанию −150% от маржи позиции, `STOP_LOSS_ROI`). При сетке на большую часть депозита ставьте его меньше (30–50), иначе ликвидация придёт раньше стопа.
- Уведомления в Telegram (необязательно).

## Запуск на Railway

1. New Project → Deploy from GitHub repo → этот репозиторий.
2. Settings → Region: Amsterdam или Singapore (Bybit блокирует US).
3. Variables: `BYBIT_API_KEY`, `BYBIT_API_SECRET`, `BYBIT_ENV` (`testnet` или `mainnet`). Остальные — по желанию, см. `.env.example`.
4. Чтобы сетки не пропадали при перезапуске: добавьте Volume (путь, например, `/data`).
5. Settings → Networking → Generate Domain — там будет страница бота.

Ключ Bybit: права Read + Contract Trade, **без** Withdrawal.

## Запуск на компьютере

Нужен Python 3.9+. Скопируйте `.env.example` в `.env`, впишите ключи и запустите:

```
python bot.py
```

Откроется страница http://127.0.0.1:8080.

## Важно

- Не запускайте одновременно на компьютере и на Railway с одним ключом — ордера будут дублироваться.
- Ордера этого бота помечены префиксом `mg`, чужие ордера и позиции на других монетах он не трогает.
- Это не финансовый совет. Сначала проверьте на testnet.
