# Grid Bot — сеточный бот для Bybit

Одна кнопка «Запустить бота», всё остальное бот делает сам. Работает на споте и на фьючерсах USDT с плечом до 100x. Один файл `bot.py`, только стандартная библиотека Python.

## Что умеет

- **Нейтральная сетка.** Диапазон ± % от цены, геометрический шаг. Купил на уровне — ставит продажу уровнем выше, продал — снова покупку ниже.
- **Фьючерсы с плечом 1–100x.** Односторонний режим, плечо ставится автоматически. Позиция закрывается до ликвидации: когда до цены ликвидации остаётся треть пути.
- **Трейлинг сетки вверх и вниз**, как в Pionex и Bybit Grid. Сдвиг на шаг за ценой, подтверждение пробоя, пределы по цене. Сдвиги оплачиваются из освобождённого ордера.
- **Радар — ранняя защита от дампа и пампа.** Лента принтов (скорость и объём против фона 10 минут), дельта агрессивных покупок и продаж, скорость цены, перекос и снятие ликвидности в стакане, открытый интерес, фандинг. При сигнале дампа снимаются покупки, при пампе — продажи. Ордера возвращаются, когда рынок успокоится. По желанию — аварийный выход при сильном дампе.
- **Минимум комиссий.** Все ордера Post-Only (мейкер). Вместо маркета — «быстрая лимитка» по лучшей цене стакана с перестановкой. Маркет только для аварийного закрытия.
- **24/7 на сервере.** После перезапуска или редеплоя бот снимает старые ордера и запускается снова, если работал.

## Запуск на Railway

1. **New Project → Deploy from GitHub repo** → выберите этот репозиторий.
2. **Settings → Region:** Europe West (Amsterdam) или Southeast Asia (Singapore). Bybit блокирует IP из США.
3. **Variables:**
   - `APP_PASSWORD` — пароль страницы бота (обязательно, без него управление заблокировано).
   - `BYBIT_API_KEY`, `BYBIT_API_SECRET` — ключ Bybit.
   - `BYBIT_ENV` — `testnet`, `demo` или `mainnet`.
4. **Volume:** правой кнопкой по сервису → Attach Volume, путь `/data`. В нём хранятся настройки и флаг автозапуска.
5. **Settings → Networking → Generate Domain.** Откройте адрес, введите пароль (логин любой), нажмите «Запустить бота».

### Ключ Bybit

- Права: «Спот торговля» и/или «Контракты: ордера и позиции». **Без вывода средств.**
- Привязка к IP: у Railway без платного Static IP адрес меняется, поэтому ключ будет без привязки. Тем важнее не давать право вывода.
- Testnet-ключи создаются на testnet.bybit.com, demo — в режиме «Демо-торговля» на bybit.com.

## Локально

```
python bot.py
```

Откроется `http://127.0.0.1:8765`. Ключи вводятся на странице в «Настройках» и сохраняются в `gridbot_config.json` рядом с ботом.

## Важно

Торговля с плечом и сеточные стратегии могут привести к потере денег. Начните с testnet или demo. Это не финансовый совет.
