# Grid Pro — ручной грид-бот для Bybit

Только ручной нейтральный грид для USDT-perp, без авто-бота, сканера рынка и статистики.

## Что умеет

- Вы задаёте монету, диапазон, количество сеток, маржу и плечо. Buy стоят ниже цены, Sell — выше.
- Как только лимитка исполнилась (проверка каждые 2 с), на соседней линии ставится противоположная — микротейк.
- **Геометрическая сетка** (переключатель): линии через одинаковый %, лот растёт от цены к краю диапазона с множителем. Все лимитки вместе = маржа × плечо.
- Сетка идёт за ценой, если цена вышла из диапазона (можно выключить или задать задержку в минутах).
- Кнопки «Авто» и «Скальпинг» подбирают диапазон, шаг, количество сеток и плечо по свечам выбранной монеты.
- Критический стоп-лосс (по умолчанию −150% от маржи позиции): стоп ставится на бирже и дублируется программно. Работает только для монет, где запущена сетка.
- Уведомления в Telegram (необязательно).

## Запуск на Railway

1. New Project → Deploy from GitHub repo → этот репозиторий.
2. Settings → Region: Amsterdam или Singapore (Bybit блокирует US).
3. Variables: `BYBIT_API_KEY`, `BYBIT_API_SECRET`, `BYBIT_ENV` (`testnet` или `mainnet`). Остальные — по желанию, см. `.env.example`.
4. Чтобы сетки не пропадали при перезапуске: добавьте Volume (путь, например, `/data`).
5. Settings → Networking → Generate Domain — там будет страница бота.

Ключ Bybit: права Read + Contract Trade, **без** Withdrawal.

## Запуск на компьютере

Нужен Python 3.9+. Скопируйте `.env.example` в `.env`, впишите ключи и запустите:

```
python bot.py
```

Откроется страница http://127.0.0.1:8080.

## Важно

- Не запускайте одновременно на компьютере и на Railway с одним ключом — ордера будут дублироваться.
- Ордера этого бота помечены префиксом `mg`, чужие ордера и позиции на других монетах он не трогает.
- Это не финансовый совет. Сначала проверьте на testnet.
