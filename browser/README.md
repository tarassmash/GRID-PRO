# Бот одним HTML-файлом

`gridbot.html` — тот же сеточный бот, что на Railway, но целиком в браузере: открыть файл двойным кликом, ввести ключ Bybit в «Настройках», нажать «Запустить бота».

- Все функции версии на Railway: три режима (½ Buy · ½ Sell, лонг, только Sell), плечо, геометрические лоты, трейлинг по проценту, стопы, радар, быстрые лимитки, сканер волатильных монет, несколько сеток, сетки на весь депозит, «Закрыть все сетки».
- Запросы к Bybit подписываются прямо в браузере (HMAC-SHA256), ключ хранится только в этом браузере.
- Бот работает, пока вкладка открыта. При следующем открытии предложит перезапустить сетки, которые работали, или снять их ордера.

Как пересобрать после изменений в `bot.py`: `python browser/build_html.py browser/gridbot.html` (берёт страницу из `bot.py` и движок из `engine.js`).

## Ссылка через Railway

Папка `browser` разворачивается на Railway отдельным проектом: Root Directory `/browser`, сборка по `browser/Dockerfile`.
Сервер `serve.py` только отдаёт страницу — торгует браузер того, кто её открыл, со своим ключом.
Если задать переменную `APP_PASSWORD`, страница будет спрашивать пароль (логин любой).
